# 화이트체커 가설 점검: 합성 페르소나 조사 설계와 판정 기준

- 작성일: 2026-11-18. 응답을 받기 전에 확정한 문서이며, 결과를 본 뒤에는 고치지 않는다
- 결과의 지위: 합성 응답은 실제 사용자 조사가 아니다. 가설을 고르고 반대 논리를 모으는 용도이며, 화이트체커 자체 기준으로는 3등급 근거에 해당한다
- 데이터: NVIDIA Nemotron-Personas-Korea (CC BY 4.0), 응답 모델: Claude Opus (Claude Code 서브에이전트), 단일 모델

## 2. 응답자 구성 (5개 군 × 40명 = 200명)

| 군 | 대상 | 데이터셋 직업(occupation) | 부여하는 역할 |
| --- | --- | --- | --- |
| G1 | 언론 | 기자 계열 | 기사·칼럼을 쓰거나 다른 사람의 원고를 데스킹·교열 |
| G2 | 기업 홍보·마케팅 | 광고·홍보 계열 20명, 마케팅 계열 20명 | 보도자료, 회사 소개 자료, 블로그·뉴스레터 글 작성 |
| G3 | 공공기관·지자체 홍보 | 지방·국가·공공 행정 사무원과 전문가 | 보도자료, 행사·제도 안내문, 소식지 작성 |
| G4 | 출판·교육·건강 콘텐츠 | 출판물 편집자, 출판 및 자료편집 사무원, 미디어 콘텐츠 창작자 등 | 교양서·교재·건강 정보 글 같은 정보성 원고 작성·편집 |
| G5 | 통제군 | 대외 발행물을 만들지 않는 일반 사무직 | 사내 보고서·회의 자료·업무 메일 작성 |

- 추출: 내려받은 데이터에서 직업 문자열로 걸러 고정 시드(20261118)로 무작위 추출. '전직', '구직', '무직'이 든 직업과 25세 미만·65세 이상은 제외
- 상황 조건: 데이터셋에 업무 방식 정보가 없으므로 세 조건을 설계자가 지정한다. 군마다 2×2×2 = 8개 조합에 5명씩 배정
  - AI 초안: 생성형 AI를 일상적으로 사용 / 사용하지 않음
  - 조직 규모: 10명 미만 / 100명 이상
  - 검토 체계: 발행 전 검토해 주는 사람이 없고 본인이 최종 책임 / 상급자나 담당 부서의 검토 절차가 있음
- 집합 정의: T = G1~G4(160명), C = G5(40명), T_AI = T 중 AI 사용(80명), T_core = T 중 AI 사용이면서 검토자 없음(40명)

## 3. 조사 절차

응답자 한 명당 서브에이전트를 두 번 따로 호출한다. 한 맥락에서 여러 인물을 연기시키지 않는다.

- **1단계(제품 노출 전, 중립 조사)**: 사실 확인이라는 주제를 드러내지 않고 업무 단계의 부담만 묻는다
  - Q1 글 한 편을 내보내기까지 시간과 신경이 많이 쓰이는 단계 상위 3개(7개 단계 중: 기획·자료 조사, 초안 작성, 사실관계·출처 재확인, 문장 다듬기·교정, 내부 검토·승인 대응, 디자인·편집·배포, 내보낸 뒤 문의·정정 대응)
  - Q2 도움을 가장 받고 싶은 단계 1개
  - Q3 한 편당 전체 소요 시간
  - Q4 최근 반년 사이 내보낸 글에서 나중에 고쳐야 했던 문제 중 가장 기억에 남는 것(자유 서술)과 그 유형
  - Q5 이 조사의 목적이 무엇이라고 생각했는지(목적 노출 점검용)
- **2단계(사실 확인 실태와 도구 비교)**: 1단계 답을 함께 주고 이어서 묻는다
  - Q6 지금 사실관계·출처를 확인하는 방법(복수 선택)
  - Q7 한 편당 사실 확인 시간
  - Q8 최근 반년 사이 겪은 오류 유형(복수 선택)과 가장 잦은 유형. 기획서의 네 유형(T1 2차 자료 의존, T2 한정어, T3 검증 뒤 변형, T4 시차)에 기획서에 없는 대조 유형 세 개(F1 AI가 지어낸 출처·인용, F2 숫자 단위·계산, F3 인명·기관명 표기)를 섞어 제시
  - 네 가지 방식을 이름 없이 설명만으로 제시: 범용 AI 검색에 붙여 넣기(AISEARCH), 문장별 판정표 도구(CLAIMTABLE, 화이트체커에 해당), 근거 없이 점수만 주는 도구(SCORE, 가짜 대조), 지금 방식 유지(CURRENT)
  - Q9 방식별 도움 정도 1~5점, Q10 하나만 고른다면, Q11 고른 이유
  - Q12 판정표 도구를 쓰지 않거나 망설일 이유(최대 2개)
  - Q13 수정 제안 반영 방식: 자동 반영 후 통보 / 하나씩 채택·보류 / 위험도 낮은 것만 자동
  - Q14 발행 전 원고를 외부 웹 도구에 올릴 수 있는지: 바로 가능 / 조건부 / 불가, 그 조건이나 사유
  - Q15 '일치' 판정 문장의 처리: 전부 재확인 / 중요한 것만 / 몇 개만 무작위 / 재확인 안 함
- 선택지 순서(업무 단계, 오류 유형, 네 방식)는 응답자마다 무작위로 섞는다
- 화이트체커라는 이름과 조사 의뢰자는 밝히지 않는다. "쓰시겠습니까" 식의 직접 질문은 넣지 않는다

## 4. 판정 기준

FACT_TOP3(집합) = 그 집합에서 Q1 상위 3개에 '사실관계·출처 재확인'을 넣은 응답자 비율.

| 가설 | 지지 | 약화 |
| --- | --- | --- |
| H1 | FACT_TOP3(T_core) ≥ 50% 이고, FACT_TOP3(T_core) − FACT_TOP3(C) ≥ 20%p | FACT_TOP3(T_core) < 30% 이거나, 통제군과의 차이 < 10%p |
| H2 | T_AI에서 네 유형(T1~T4) 선택률이 모두 ≥ 40% 이고, '가장 잦은 유형' 1위가 네 유형 중 하나 | 네 유형 중 둘 이상이 선택률 < 20% 이거나, 대조 유형(F1~F3)이 '가장 잦은 유형' 1위 |
| H3 | T에서 CLAIMTABLE 선택 ≥ 50% 이고, AISEARCH 선택보다 20%p 이상 높음 | AISEARCH 선택 ≥ CLAIMTABLE 선택 이거나, AISEARCH + CURRENT 선택 ≥ 60% |
| H5 | T에서 '하나씩 채택·보류' ≥ 50% | '하나씩 채택·보류' ≤ 40% |
| H6 | T에서 '바로 가능' ≥ 60% 이고, '불가'가 30% 이상인 대상 군이 없음 | '바로 가능' < 40% 이거나, '불가' ≥ 30%인 대상 군이 있음 |
| H7 | G1~G4 중 3개 군 이상이 통과 | 통과한 군이 1개 이하 |

- 두 조건 어느 쪽에도 들지 않으면 '판단 불가'
- H3 선결 조건: T에서 CLAIMTABLE 평균 점수 − SCORE 평균 점수 < 0.5 이면 응답이 도구를 구별하지 못한 것으로 보고 '판단 불가'
- H7의 군별 통과 조건: FACT_TOP3(군) − FACT_TOP3(C) ≥ 20%p 이고, 그 군의 CLAIMTABLE 선택 ≥ 40%

## 5. 조사 자체의 점검 (보정 장치)

| 점검 | 기준 | 미달 시 처리 |
| --- | --- | --- |
| V1 통제군 구별 | FACT_TOP3(C) < 50% | H1·H7에 '구별력 부족' 표시 |
| V2 가짜 대조 구별 | CLAIMTABLE − SCORE 평균 점수 차 ≥ 0.5 | H3 판단 불가 |
| V3 반복 안정성 | 20명(군별 4명)을 한 번 더 실행. 핵심 4문항(사실 재확인의 상위 3위 포함 여부, Q10, Q13, Q14) 일치율이 문항마다 ≥ 80% | 해당 문항을 쓰는 가설에 '불안정' 표시 |
| V4 목적 노출 | 1단계에서 조사 목적을 사실 확인·팩트체크 관련으로 짐작한 비율 ≤ 20% | H1·H7에 '목적 노출' 표시 |
| V5 상황 일관성 | AI 미사용 조건에서 F1(AI가 지어낸 출처)을 겪었다고 답한 비율 등 | 비율을 보고 |

## 6. 알려진 한계

- 응답 모델이 하나뿐이어서 모델 간 비교는 하지 못한다
- 겪은 오류, 걸리는 시간 같은 '경험'은 모델이 직업과 상황으로부터 추정해 답한 것이다. 실제 빈도나 시간으로 읽지 않는다
- 데이터셋에는 뉴스레터 편집자, 교열자, 번역가에 해당하는 직업이 없다. 핵심 고객에 대한 H1·H2는 실제 발행인 인터뷰로 확인해야 한다
- 군별 40명, 조합별 5명이어서 조합 단위의 비율은 참고로만 본다

## 7. 시범 실행 후 변경 (2026-11-18, 본 실행 전)

10명 시범 실행(호출 20개)과, 대화 전달이 없는 별도 호출 4개로 조사 도구를 점검한 뒤 아래를 바꿨다. 4절의 판정 기준과 5절의 점검 기준은 바꾸지 않았다. 시범 응답은 판정에 쓰지 않고 `pilot/`에 따로 둔다.

- **발견 1**: 워크플로 실행 도구가 서브에이전트마다 직전 대화(사용자 요청과 그 앞의 답변)를 전달해, 응답자가 조사 주제를 미리 알았다. 시범 10명 중 5명이 1단계에서 조사 목적을 사실 확인 관련으로 짐작했다
  - 조치: 본 실행은 주제가 드러나지 않는 짧은 요청 직후에 시작하고, 시작 전에 호출 1개로 전달 내용을 확인한다
- **발견 2**: 대화 전달이 없어도 'AI로 초안을 쓴다'는 조건이 주어지면 통제군을 포함해 사실 재확인을 1위 부담으로 꼽았다(별도 호출 4명 중 AI 사용 3명 전원). 상위 3위 포함 여부만으로는 군 사이의 차이가 드러나지 않을 수 있다
  - 조치: 1단계에 단계별 시간 비중 문항(Q1-2, 일곱 단계의 합 100)을 추가해 참고 지표로 함께 보고한다. 판정에는 쓰지 않는다
- **발견 3**: Q2의 '도구나 다른 사람의 도움'이라는 표현 때문에 조사 목적을 도구 수요 조사로 짐작한 응답이 많았다(시범 10명 중 6명)
  - 조치: Q2를 '누가 대신 맡아 준다면 가장 먼저 덜어 내고 싶은 단계'로 바꿨다
- **예상**: 발견 2 때문에 V1(통제군 구별)과 V4(목적 노출)가 미달로 나올 수 있다. 그 경우 사전에 정한 대로 H1·H7에 주의 표시를 붙인다
- **본 실행 규모**: 응답자 200명과 반복 20명, 각각 두 번 호출해 모두 440개 호출
